## Featured Projects

### Network Troubleshooting Intelligence Platform

**Independent Project | Network Engineering & Diagnostics**

A virtual network troubleshooting platform built to investigate routing, switching, and connectivity problems using collected network evidence.

The project includes:
- A Containerlab environment with two FRRouting routers, two Open vSwitch switches, and four Linux hosts.
- Network evidence collection using SSH and Syslog, with SQLite for evidence storage.
- A diagnostic workflow that compares observed network conditions against a known-good baseline and produces reports with findings, evidence, and recommendations.
- Four troubleshooting scenarios covering VLAN trunk misconfigurations, OSPF neighbor failures, interface outages, and configuration-change correlation.
- Validation through **20 documented lab test runs** and **30 Python regression tests**, all passing their defined checks.

The project strengthened my understanding of network fault isolation, Linux-based networking environments, evidence collection, and the importance of verifying both failures and recovery.

**[GitHub Repository](https://github.com/norah-sudo/network-troubleshooting-intelligence-platform) | [Project Showcase](https://norah-sudo.github.io/network-troubleshooting-intelligence-platform/)**
